# Standing rules

- Never modify files, configs, or system state without explicit user consent.
  Propose the exact change (diff or command) first; apply only after the user
  explicitly approves ("yes", "do it", "apply", etc.).
- Never create git commits or install software without explicit user approval
  per action ("commit it", "install X", etc.). Propose the exact command first.
- Read-only inspection (listing files, reading configs, searching docs) does
  not require consent.
